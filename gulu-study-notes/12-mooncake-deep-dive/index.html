METHOD每一课怎么读源码

先画所有权

谁决定地址、谁拥有内存、谁只保存元数据。分布式系统最危险的误解，通常不是 API，而是 ownership。

再追状态转移

调用成功不等于数据可见。重点寻找 begin/commit、submit/completion、lease/expire 这些边界。

最后量化

每条路径都写成：固定开销 + 字节数/有效带宽 + 排队 + 未被 overlap 的部分，再用 trace 验证。

EXIT学完的判断标准

  • 能从 SGLang 的 Python 调用定位到 Mooncake C++ transport，而不把控制面 RPC 当成 KV 数据路径。
  • 能解释 RDMA 注册为何昂贵、为何应该复用，以及带宽满但 TTFT 未下降的常见原因。
  • 能区分 PD 的一次点对点 KV 交接与 HiCache 的 key→replica 存储语义。
  • 能用第 7 课计算器给出链路、缓存、并发和 SLO 的数量级判断。
