学习路径 源码索引

Mixture of Experts (MoE) 是当前大模型扩容的核心范式——用 稀疏激活 在不增加每个 token 计算量的前提下，将模型参数量提升 4-16 倍。SGLang 对 MoE 有完整的生产级实现：从 router topk、fused expert GEMM 到 Expert Parallelism (DeepEP / Mooncake)。

学习路径：

  1. 先看 01 MoE 原理 理解稀疏激活的本质、为什么比 Dense 模型更难 serve
  2. 再看 02 架构总览 建立 SGLang MoE 的全景骨架（5 层抽象）
  3. 然后按 03 → 04 → 05 顺序逐层深入：TopK / Router → FusedMoE Layer → Triton Kernel
  4. 06 Expert Parallelism 讲多卡分布式 MoE（DeepEP / All-to-All）
  5. 最后 07 覆盖生产调优和性能分析
