§1GPU 这块硅到底是什么

先回答一个问题：一颗 H100（H100-SXM5）到底是什么？

把这些数字拆成一句人话：GPU = 一大堆能独立跑的"小 CPU"（SM）+ 一块巨大但"慢"的共享显存（HBM）+ 高速把卡连起来的网络（NVLink）。

和 CPU 的根本差别：CPU 是「少量超强核 + 多级缓存优化单线程延迟」，GPU 是「海量弱核 + 大带宽内存优化吞吐量」。H100 的单个 CUDA core 只能跑到 ~1.8GHz、IPC 远低于 x86 核；但它有 132×128 = 16896 个 FP32 ALU，同一周期同时开工——靠数量打败质量。

为什么叫 GPC？历史遗留：GPU 诞生时是画三角形的，每个 GPC 里的 Raster Engine 负责光栅化一块屏幕。AI 时代光栅化用得少，但这套组织仍保留——因为它解决了"如何把 100+ 个 SM 分层分发任务"的电路问题。GigaThread Engine 向 GPC 派发 thread block，GPC 再往下派发到 SM。

可视化：SM 数量 + HBM 带宽的指数曲线

看出两条规律：
  • SM 数量每代约 +30%（摩尔定律的另一种表达：晶体管多了就多切 SM）。
  • HBM 带宽每代近乎 ×1.5，Blackwell HBM3e 到了 8TB/s——LLM decode 是 memory-bound，带宽就是命。

§4为什么每代都在堆 Tensor Core

回到 LLM 视角看这个演进。大模型训练/推理 99% 的 FLOPS 都花在矩阵乘法（GEMM）上：Attention 是 QKᵀ 和 PV 两次 GEMM，FFN 是 two-linear 两次 GEMM，LoRA/量化/KV projection 还是 GEMM——全部是 GEMM。

普通 CUDA core 跑 GEMM 的效率是多少？举例：H100 单 SM 有 128 个 FP32 CUDA core，跑 FMA（fused multiply-add）每周期 256 ops，@ 1.8GHz = 0.46 TFLOPS/SM × 132 SM = 60 TFLOPS。

同一 SM 的 Tensor Core 跑 FP16 MMA：每周期 1024 ops × 4 TC/SM = 4096 ops/周期 × 1.8GHz × 132 SM = 989 TFLOPS。

16.5× 的差距 · 而且只占 die 面积的一小块

精度不停下探：FP32 → FP16 → BF16 → FP8 → FP4。每降一位，同样晶体管能堆两倍吞吐（乘法器面积 ≈ bit²）。LLM 可以承受降精度的原因：权重分布近高斯 + 激活有大量 outlier 但可缩放。第 5 章 Tensor Core 深度会把每代 MMA 指令的形状拆开讲。

记住一个比例：SRAM 比 HBM 快 5-10×、HBM 比 NVLink 快 4×、NVLink 比 PCIe 快 8×、PCIe 比网络快 2-3×。做任何分布式优化都在这条层级上跳——目标是把数据往"上"挪。

三、容量金字塔

直觉：H100 一共 30MB 的"宝贵 SRAM"——装不下 70B 模型的任何一层。一层 FFN 权重（4096×16384 BF16 = 134MB）就得 4 次 HBM→SRAM 流水复制。这就是所有 GEMM tiling 的根本动机：切块装进 SRAM 算完再搬下一块。

§6带走的六句话

  1. GPU 是"一大堆小 CPU + 巨大慢显存"——132 SM × 128 FP32 ALU = 16896 个算术单元并行干活，靠数量赢。
  2. die 的层级是 GPC → TPC → SM → sub-partition → CUDA core/Tensor Core。下一章我们钻进 SM 内部。
  3. 每代 GPU 的本质变化只有三件事：SM 变多、精度变低、带宽变大——所有 feature（TMA、Cluster、FP8、FP4）都是这三件事的衍生。
  4. Tensor Core 比 CUDA core 快 16-32×，LLM 吃的就是 Tensor Core；CUDA core 今天主要服务于 layer norm、softmax、采样等 elementwise 工作。
  5. 内存金字塔 5 级延迟/带宽差 6000×。"HBM 是唯一的瓶颈"是过度简化——真正的 art 是把正确的数据在正确的时机搬到正确的层级。
  6. Hopper/Blackwell 新 feature 都在攻"内存&调度"的最后一公里：TMA 自动化 LDG、Cluster 让 SM 之间共享 SMEM、NV-HBI 把两块 die 黏成一块——都不再是"算得快"而是"数据来得快"。
